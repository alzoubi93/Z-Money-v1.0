# Z.Money v1.0

## المرحلة الأولى من النسخة المالية المتكاملة
- لوحة مالية وملخص ذكي للشهر.
- نظام الميزانية والتصنيفات من v0.9.
- أهداف الادخار:
  - اسم الهدف.
  - المبلغ المستهدف.
  - المبلغ المدخر.
  - العملة.
  - تاريخ مستهدف اختياري.
  - إضافة مبالغ وتقدم تلقائي.
- مركز التنبيهات:
  - اقتراب الميزانية من 80%.
  - تجاوز 100%.
  - استحقاق الديون.
  - الملخص الشهري.
- إدارة أفراد العائلة والتقارير والديون مستمرة.

## Web-first
هذه النسخة مخصصة حاليًا للويب. لا يوجد انتقال إلى APK في هذه المرحلة.

## التشغيل
npm install
npm run dev
